# DevOps Mastery Specialization
The **DevOps Mastery Specialization** on Coursera is an 8-course program designed to equip you with essential DevOps skills. Here's a concise overview:

**Courses and Instructors:**

1. [**DevOps Prerequisite Course**](./1_devops-prerequisite-course/readme.md)
   - *Instructor:* [Mumshad Mannambeth](https://www.coursera.org/instructor/~93669146)
   - *Duration:* 14 hours
   - *Rating:* 4.6 (32 ratings)
   - *Overview:* Covers foundational skills like Linux basics, VirtualBox setup, and common applications such as Java, Python, and NodeJS.

2. [**Git Basics for DevOps**](./2_git-basics-for-devops/readme.md)
   - *Instructor:* [Lydia Halie](https://www.coursera.org/instructor/~150727055)
   - *Duration:* 4 hours
   - *Overview:* Introduces version control using Git, essential for tracking code changes.

3. [**Jenkins for Beginners**](./3_jenkins-for-beginners/readme.md)
   - *Instructor:* [Michael Levan](https://www.coursera.org/instructor/~156404805)
   - *Duration:* 4 hours
   - *Overview:* Teaches continuous integration and delivery using Jenkins.

4. [**Docker Basics for DevOps**](./4_docker-basics-for-devops/readme.md)
   - *Instructor:* [Mumshad Mannambeth](https://www.coursera.org/instructor/~93669146)
   - *Duration:* 7 hours
   - *Rating:* 4.5 (10 ratings)
   - *Overview:* Covers containerization concepts with Docker.

5. [**Kubernetes Basics for DevOps**](./5_kubernetes-basics-for-devops/readme.md)
   - *Instructor:* [Mumshad Mannambeth](https://www.coursera.org/instructor/~93669146)
   - *Duration:* 8 hours
   - *Overview:* Focuses on container orchestration using Kubernetes.

6. **Ansible for the Absolute Beginners**
   - *Instructor:* [Mumshad Mannambeth](https://www.coursera.org/instructor/~93669146)
   - *Duration:* 10 hours
   - *Overview:* Introduces configuration management with Ansible.

7. **Terraform for the Absolute Beginner with Hands-on Labs**
   - *Instructor:* [Mumshad Mannambeth](https://www.coursera.org/instructor/~93669146)
   - *Duration:* 15 hours
   - *Overview:* Teaches infrastructure as code using Terraform.

8. **Python for the Absolute Beginner**
   - *Instructor:* [Lydia Halie](https://www.coursera.org/instructor/~150727055)
   - *Duration:* 34 hours
   - *Overview:* Provides a foundation in Python programming.

**Skills You'll Gain:**

- **Python Programming**
- **DevOps Practices**
- **Terraform**
- **Kubernetes**
- **Docker**
- **Git Version Control**
- **Jenkins**
- **Ansible**

**Program Details:**

- **Level:** Beginner (No prior experience required)
- **Duration:** Approximately 3 months (10 hours per week)
- **Flexible Schedule:** Learn at your own pace
- **Certificate:** Shareable upon completion

This specialization offers hands-on projects to apply your skills in real-world scenarios, preparing you for a career in DevOps.

For more information, visit the [DevOps Mastery Specialization on Coursera](https://www.coursera.org/specializations/devops-mastery).
